# ReChiplet
Multi-Product Chiplet Lifecycle Optimizer — foundation build.

## Stack
React + Vite + TypeScript + Tailwind + Plotly.js; FastAPI + SQLAlchemy + Alembic; DEAP NSGA-II; SQLite.

## Windows setup
Extract to `C:\Users\Milan Sharma\Desktop\ReChiplet`, then double-click `start.bat`.
Frontend: http://localhost:5173 · API docs: http://127.0.0.1:8000/docs

Requires Python 3.11+ and Node.js 20+. The launcher creates a venv, installs dependencies, runs Alembic migrations, seeds sample data, and starts both servers.

The included portfolio data and engineering estimates are synthetic demonstration data, not measured silicon data or sign-off results.
